## 📌 About SATARK AI

**SATARK AI** is an intelligent, multi-stakeholder digital platform designed for the **Department of Higher & Technical Education, Government of Jharkhand** to crowdsource grassroots societal challenges and connect them with **Government, Universities, Students, Faculty, and Industry** to move from mere problem identification towards tangible, deployable solutions.

The platform goes far beyond conventional grievance-reporting portals by introducing an **AI-assisted triaging workflow** that analyses challenges, weeds out duplicates, predicts priority, and matches validated problems with specialized academic R&D labs and corporate CSR funding partners.

---

## 🚨 The Core Problem

Across India, societal challenges (such as contaminated rural borewells, urban waterlogging, clinic medicine deficits, and road hazards) are reported through fragmented, uncoordinated channels. This creates severe systemic friction:

- **Citizens Lack Structured Mechanisms**: Reporting civic issues often involves complex paperwork, obscure portals, or language barriers, leaving rural and semi-literate citizens unheard.
- **Authorities Face Unstructured Backlogs**: Government departments receive thousands of raw, unclassified complaints without clear severity metrics or SLA prioritization.
- **Academic Potential is Disconnected**: Universities produce thousands of capable student engineers whose academic capstone projects remain theoretical simulations rather than real-world societal solutions.
- **Industry CSR Funding Lacks Visibility**: Corporate CSR divisions and foundations have the capital and mentorship to fund impactful prototypes, but lack a verified, auditable pipeline of grassroots problems.
- **Repetitive Duplicate Complaints**: Identical challenges are reported dozens of times across localities, resulting in fragmented municipal responses and wasted public funds.

**SATARK AI bridges this gap by creating an unbroken, collaborative journey from problem identification to real-world solution.**

---

## 💡 Our Solution

SATARK AI unites every ecosystem participant into a continuous innovation pipeline:

$$\text{Citizen} \longrightarrow \text{Government} \longrightarrow \text{University} \longrightarrow \text{Student/Faculty} \longrightarrow \text{Industry} \longrightarrow \text{Solution} \longrightarrow \text{Impact}$$

1. **Inclusive Reporting**: Citizens submit societal challenges with multimodal data (text description, photos, GPS coordinates, or native voice dictation via the multilingual Voice AI Console).
2. **Automated AI Triaging**: A 5-module AI layer categorizes the domain, calculates an explainable 0–100 priority score, filters duplicates, recommends HEIs, and suggests initial solution directions.
3. **Government Validation**: Department administrators review and validate the challenge with a transparent human-in-the-loop audit trail.
4. **University Collaboration**: Validated challenges are matched with premier institutions (e.g. BIT Mesra, NIT Jamshedpur, IIT ISM Dhanbad) where multidisciplinary student teams assemble under faculty mentorship.
5. **Industry & CSR Synergy**: Corporate partners (such as Tata Steel CSR, Coal India R&D) sponsor prototypes with milestone-based INR ₹ grants, laboratory equipment, and engineering mentorship.
6. **Tangible Field Impact**: Prototypes undergo field pilot trials, leading to filed patents, incubated student startups, and permanent community resolution.

## 🤖 Five Core AI Modules

SATARK AI's intelligence engine operates with a **dual-mode architecture**: it leverages **LangChain + OpenAI GPT-4o** for advanced semantic inference, backed by a **deterministic rule-based heuristic pipeline** ensuring 100% offline resilience and zero cloud downtime.

```
                              [ Citizen Description + Photo + Geolocation ]
                                                    │
                 ┌──────────────────────────────────┴──────────────────────────────────┐
                 ▼                                                                     ▼
     [ Module 1: Classification ]                                          [ Module 2: Priority Index ]
  Maps into 12 Civic Domains:                                         Multi-Factor 0-100 Scoring:
  Water Resources, Healthcare, Agriculture,                           • Population Impact Weight (40%)
  Urban Infrastructure, Sanitation, Energy, etc.                      • Hazard Severity (30%)
                 │                                                    • Infrastructure Criticality (20%)
                 │                                                    • Public Safety Risk (10%)
                 ▼                                                                     │
     [ Module 3: Vector Deduplication ]                                                │
  • pgvector Semantic Cosine Similarity                                                ▼
  • Haversine Spatial Distance (<1.5 km)                                   [ Module 4: HEI Matching ]
  Flags duplicate entries to prevent wasted funds                     Matches challenges to HEIs:
                 │                                                    • BIT Mesra (Water & Environment)
                 ▼                                                    • NIT Jamshedpur (Structural & Energy)
     [ Module 5: Solution Directions ]                                • IIT ISM Dhanbad (Mining & Hydrology)
  Generates 3-4 actionable engineering approaches                     • Ranchi University (Public Health)
  (e.g., Solar Bio-Sand Filter, Computer Vision Pavement Audit)
```

1. **Problem Classification**: Parses natural language input and categorizes it across 12 societal domains (Water Resources, Healthcare, Agriculture, Urban Infrastructure, Energy, Sanitation, etc.) to immediately route it to the right administrative department.
2. **Priority Prediction**: Computes an objective **0–100 Priority Score** accompanied by explainable justifications (e.g. *"Fluoride contamination directly threatens drinking water safety for 400+ villagers in Angara"*). Final validation remains in human administrative hands.
3. **Duplicate Detection**: Computes semantic text vector cosine similarity alongside GIS Haversine proximity (<1,500 meters) to detect duplicate challenges, conserving administrative and academic resources.
4. **University Recommendation**: Evaluates university curriculum, accredited laboratories, and faculty specializations across Jharkhand (BIT Mesra, NIT Jamshedpur, IIT ISM Dhanbad, Ranchi University) to recommend the optimal academic research partner.
5. **Solution Recommendation**: Generates 3–4 foundational engineering solution directions (e.g., modular solar bio-sand filtration, IoT telemetry nodes) to kick-start student ideation during the early stages of project formulation.

The Citizen Portal allows users to submit societal challenges with relevant information and track their progress.

## 🔐 Security & Access Control

SATARK AI uses fine-grained **Role-Based Access Control (RBAC)** across 9 distinct stakeholder roles:

- **JWT-Based Authentication**: Secure stateless token issuance with configurable expiration and session invalidation.
- **Dual OTP Verification**: Support for both SMS mobile OTP and Gmail SMTP OTP (`backend/app/api/otp.py`) for frictionless citizen authentication.
- **Strict Least-Privilege API Protection**: Endpoints enforce role verification so that sensitive state actions (such as HEI assignment or AI overrides) are restricted to authorized personnel.
- **Human-in-the-Loop Governance**: While AI generates priority scores and solution pathways, all critical decisions (validation, overriding severity, fund disbursement) require verified human sign-off with mandatory audit logging.

## 🌟 What Makes SATARK AI Different?

Most existing civic platforms focus purely on complaint dispatching or generic innovation competitions. SATARK AI changes the entire paradigm:

### ❌ Conventional Flow
$$\text{Problem} \longrightarrow \text{Report} \longrightarrow \text{Route} \longrightarrow \text{Resolve (Often Temporary)}$$
*Issues are treated as isolated complaints; root causes remain unaddressed; solutions often degrade rapidly.*

### ✅ SATARK AI Flow
$$\text{Problem} \longrightarrow \text{AI Analysis} \longrightarrow \text{Validation} \longrightarrow \text{University Matching} \longrightarrow \text{Student + Faculty Team} \longrightarrow \text{Industry Collaboration} \longrightarrow \text{Solution Development} \longrightarrow \text{Real-World Impact}$$
*Every challenge becomes an active engineering project backed by academic research, monitored by government, funded by industry CSR, and deployed for permanent community benefit.*

## 🚀 Running the Project Locally

### 1. Prerequisites
- **Python**: 3.10+ (Tested through Python 3.14)
- **Node.js**: v18.0+ & `npm`
- **Git**
- *(Optional)*: PostgreSQL with `pgvector` & Redis (SQLite fallback is enabled by default)

### 2. Clone the Repository
```bash
git clone https://github.com/HariKrishnahk1/SATARK-AI-Team-404-Found-Us.git
cd SATARK-AI-Team-404-Found-Us
```

### 3. Backend Setup
```bash
# Install backend dependencies
pip install -r backend/requirements.txt

# Seed realistic Jharkhand demo data (Users, Challenges, HEIs, CSR Pledges, Milestones)
# Windows PowerShell:
$env:PYTHONPATH="backend"
python backend/seed.py

# Linux / macOS:
# PYTHONPATH=backend python backend/seed.py

# Start FastAPI backend server (Runs on port 8008)
python -m uvicorn app.main:app --host 0.0.0.0 --port 8008 --reload
```
> Interactive Swagger API Documentation is accessible at: **`http://localhost:8008/docs`**

### 4. Frontend Setup
```bash
# Open a new terminal in the frontend directory
cd frontend

# Install dependencies
npm install

# Start Next.js development server (Runs on port 3000)
npm run dev
```
> Access the unified application at: **`http://localhost:3000`**
